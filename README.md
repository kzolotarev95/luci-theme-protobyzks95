# LuCI Theme Proto by ZKS95

Кастомная тема для OpenWrt LuCI на базе Proton2025 с доработанным интерфейсом, золотыми акцентами, анимациями, кастомным логотипом входа, улучшенными progressbar-индикаторами и автоматическим сбросом кэша после установки.

Репозиторий: `kzolotarev95/luci-theme-protobyzks95`

---

## Возможности

### Общий интерфейс

- Кастомный стиль Proton2025 для OpenWrt LuCI
- Тёмный современный интерфейс
- Золотые акценты
- Улучшенные карточки и блоки интерфейса
- Скрытие стандартного footer блока LuCI / OpenWrt / Proton2025
- Поддержка русскоязычного интерфейса
- Автоматическая очистка LuCI cache после установки и удаления
